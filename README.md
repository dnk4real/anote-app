# anote repository

## Structure

- `apps/mobile`: current Expo mobile app
- `apps/desktop`: future desktop app shell
- `packages/shared-types`: shared contracts for notes, sync, and settings
- `packages/sync-core`: future shared sync implementation

## Commands

- `npm run mobile:start`
- `npm run mobile:android`
- `npm run mobile:web`
- `npm run mobile:lint`

Run commands from the repository root. The mobile app lives in `apps/mobile`.
